# Index Moldova Revision Lists

Bessarabian poll tax censuses (catagrafii, ревизские сказки), 1824-1886: from a village name to the archival file (ANRM fond 134 opis 2) and to its images on FamilySearch.

Site: https://index-moldova-revision-lists.github.io/ (English, Română, Français, Русский)

Machine-readable data: `data/` and `llms.txt`. Everything here is released under CC0 1.0 (see LICENSE).
